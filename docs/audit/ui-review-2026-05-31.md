# UI Visual Review — M3 screens (2026-05-31)

> A design-led visual review of the three M3 screens (home, candidates, route detail), judged against the [UX & grading checklist](../level-2-architecture/ux-and-rubric-checklist-2026-05-31.md) (Prof. Baresi's 5 principles + 4 anti-patterns + Material 3 / WCAG) and the [visual design direction](../level-2-architecture/visual-design-direction-2026-05-31.md) (Theme A), with `frontend-design` judgment. Screenshots reviewed: `docs/screenshots/{m32-home,m3-candidates,m3-detail}.png`.
>
> Each finding was re-checked against the actual code before action — some were already implemented or were screenshot misreads (noted under "Not actioned").

## Applied in this polish pass

| ID | Screen | Change |
|---|---|---|
| H6 | Candidates | Map preview height 120 → 140 (loop reads better) |
| H8 | Detail | Elevation chart now labels peak + valley elevations (no other chart elements — anti-pattern-safe) |
| H3 | Home | Explicit green `SliderTheme` (active track + thumb = primary green) instead of M3 defaults |
| M5 | Candidates | Card content padding 12 → 16 (Material 3 spacing) |
| — | Detail | Detail score given a brand colour (primary green) instead of plain dark |
| M3 | Home | Each weight slider now shows a Low/Med/High readout |

## Not actioned (already done / misread / wrong-milestone)

- **#1 score amber (H4/SYS-2):** already implemented on candidate cards (`rank == 1 ? amber`). The detail score is the only place lacking a brand colour — addressed above (green, since a detail route isn't necessarily the #1-ranked one, so amber-reserved-for-#1 does not apply).
- **Sora/DM Sans not differentiated (SYS-1):** screenshot misread — the theme maps Sora to display/title/scores and DM Sans to body; app-bar titles render in Sora.
- **Current-location marker (L1/M9/SYS-3):** deferred to **M4.2** — there is no live GPS yet (home uses a Milan default), so a "you are here" dot belongs with real tracking.
- **Start / Save / Share actions (M8):** Start = M4.2 (tracking), Save = M5 (persistence), Share = later. The disabled "Start run (M4)" button is an intentional placeholder.
- **Scenery photo height (M7):** carousel is already 180dp; acceptable.

## Full finding list (for reference)

Priorities from the review: **High** — H1 home title weight, H2 distance emphasis, H3 sliders, H4 candidate score hierarchy, H5 badge contrast, H6 map preview height, H7 detail score colour, H8 elevation labels, H9 sheet handle, SYS-1 type system, SYS-2 amber accent. **Medium** — M1 terrain chip contrast, M2 sheet shadow/handle, M3 slider readout, M4 "score" label verbosity, M5 card padding, M6 candidate title weight, M7 photo height, M8 actions, M9 detail location marker. **Low** — L1 home location pin, L2 stats weight, L3 explanation weight, L4 heading weight.

Remaining medium/low items (chip contrast, sheet shadow/handle prominence, title weights, stats/heading weight differentiation) are queued for the **M6 polish pass**, where the full multi-device + look-&-feel sweep happens.
